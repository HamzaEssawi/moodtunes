# 🎵 MoodTunes - AI-Powered Spotify Playlist Generator

![Next.js](https://img.shields.io/badge/Next.js-15-black)
![TypeScript](https://img.shields.io/badge/TypeScript-5.0-blue)
![Spotify](https://img.shields.io/badge/Spotify-API-1DB954)
![License](https://img.shields.io/badge/license-MIT-green)

MoodTunes creates personalized Spotify playlists based on how you feel. Just describe your mood, and get a custom playlist instantly!

## ✨ Features    

- 🎨 **Mood Color Orb** - Animated orb that changes color with your mood
- 🎵 **Real Spotify Search** - Fetches actual songs from Spotify
- 🔄 **Refresh Button** - Get different songs for the same mood
- 🎧 **30-Second Previews** - Listen before saving
- 💾 **Save to Spotify** - One-click playlist creation
- 🌈 **Dynamic UI** - Colors change with your mood throughout the app
- 📱 **Fully Responsive** - Works on mobile, tablet, and desktop
